# Projeto Base - Cypress

Este é um projeto base para testes automatizados utilizando o **Cypress**.

## 🧩 Pré-requisitos

Antes de começar, certifique-se de ter instalado:

- [Node.js](https://nodejs.org/) (recomenda-se a versão **LTS**)
- [Git](https://git-scm.com/)

## 🚀 Passos para rodar o projeto

### 1. Clonar o repositório

```bash
git clone https://github.com/EBAC-QE/ebac-cypress-samples.git
```

### 2. Entrar na pasta do projeto

```bash
cd ebac-cypress-samples
```

### 3. Instalar as dependências

```bash
npm install
```

### 4. Rodar o Cypress (modo interativo)

```bash
npx cypress open
```

### 5. Rodar os testes (modo headless)

```bash
npx cypress run
```

# English Version

# Cypress Starter Project

This is a starter project for automated testing using **Cypress**.

## Goal

Provide a basic structure to help practice and develop automated tests with Cypress.

## Technologies

- JavaScript
- Cypress
- Node.js
- npm

## Getting Started

Install the project dependencies and run Cypress using the scripts configured in `package.json`.

Typical commands:

```bash
npm install
npx cypress open
```

Review the project's configuration and available test files before running the tests.
